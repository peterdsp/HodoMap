# iOS application

This directory will contain the native SwiftUI application.

Planned responsibilities:

- SwiftUI scenes and navigation.
- MapKit rendering.
- Core Location permissions.
- VoiceOver and Apple platform accessibility.
- External operator booking handoff.
- KMP shared-core integration.
- App Store packaging and signing.

Shared Kotlin source files must be wired into the generated framework and iOS
project explicitly as part of each implementation change.
